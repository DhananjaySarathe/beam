# Beam site

The one-page site for [Beam](https://github.com/DhananjaySarathe/beam-file-transfer), served by GitHub Pages at https://dhananjaysarathe.github.io/beam/

Plain HTML and CSS, no build step. Open `index.html` to see it.

- `index.html`, `styles.css`: the page
- `assets/`: real screenshots of Beam. Retake them with `node tools/shots.cjs <path to a beam-file-transfer checkout>` (needs Google Chrome on a Mac)
- `fonts/`: Schibsted Grotesk 800, under the SIL Open Font License (`fonts/SchibstedGrotesk-OFL.txt`)

When a new Beam version is released, update the two download links and the version line in `index.html`.
