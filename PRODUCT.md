# Beam site

One page that gets a Mac owner to download Beam, and shows everyone else where the code is.

Written from the request and from Beam itself, without an interview. Assumptions are marked.

- **Product:** Beam sends files, text and links between devices on one Wi-Fi. A Mac runs the app; every other device opens a web page. Source: github.com/DhananjaySarathe/beam-file-transfer.
- **Visitor:** someone with a Mac and a phone who is tired of moving files through a cloud drive. (Assumed from the video Beam was built for.) Second visitor: a developer who wants the source.
- **What they must find in seconds:** the two download buttons (Apple Silicon, Intel), the GitHub link, and how it works.
- **Look:** asked for minimal and light. The page uses the app's own paper, ink and amber so the site and the product are one thing; the warm off-white is the app's, not a default.
- **Honesty:** every picture is a real screenshot of Beam (tools/shots.cjs retakes them). The page says the app is unsigned and what macOS will ask, because a stranger hits that on first launch.
- **Not claimed:** speed figures, tested browsers beyond what the README says, a minimum macOS version.
